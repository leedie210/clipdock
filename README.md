# ClipDock

打开分享链接即可播放视频的轻量网页，配合 Reading Room 本地素材工具使用。

## 实际能力

- 网页内播放完整视频或片段，保留浏览器原生进度、音量与全屏控制。
- 分别复制预览页面和视频源地址。
- 显示存储服务提供的预计到期时间；已到期链接不自动重复加载。
- 提供自制合成演示，不包含个人上传素材。
- 拖入或多选本地视频后立即预览，自动逐条上传；同时最多上传两条，其他排队。分批添加不会替换已有视频。
- 上传成功后每条独立生成预览页与视频源地址，可分别复制。单个文件上限 200,000,000 字节，链接有效 24 小时。25 MB 以内使用 tdrop，较大视频通过 ClipDock 后端以 8 MiB 分片上传至 R2，可重试未完成的分片。同一网络每小时最多 10 个大文件、合计 1 GB。
- 视频列表以独立键存入当前浏览器的 IndexedDB。成功记录保存 URL、文件名、大小和到期时间；可上传但未完成的文件暂存在浏览器以供重试。到期记录保留，列表不跨设备同步，清理网站数据会清空记录。
- 大于上传限制的文件仍可本地预览，但原件不跨刷新保存。存储不可用或空间不足会提示先复制链接，不会清空当前列表。
- HTML、CSS、原生 JavaScript，无构建步骤、没有第三方统计脚本。

GitHub Pages 托管播放器与上传界面。所选视频上传至临时存储，不进入 GitHub 仓库，不需要用户提供密钥。大文件的上传授权仅保存在当前浏览器，不进入分享 URL。视频也可由本地素材工具上传。页面不能延长原文件的保存期限；获得链接的人可访问对应视频。本地 blob 预览不会被误当成可分享链接，上传成功才启用复制按钮。大文件后端按到期时间拒绝播放，在后续访问和新上传时清理过期文件，物理删除可能晚于链接失效。

## 分享格式

`https://<用户名>.github.io/clipdock/#src=<编码后的视频源URL>&title=<标题>&expires=<ISO到期时间>`

参数存于 URL fragment。标题使用文本渲染，视频只允许不含登录凭据的 HTTPS URL。

本地工具应保存预览页 URL 与媒体 URL，复制分享时优先返回预览页。需要直接抓取媒体的机器人可使用源地址，网页可播放不等于所有机器人都能读取。

## 本地预览

运行 `python -m http.server 8000 --bind 127.0.0.1`，访问 `http://127.0.0.1:8000/`。

## GitHub Pages

将本目录的公开文件上传到 `clipdock` 仓库，在 Settings / Pages 选择从 main 分支根目录发布。不上传 `.local`、任何用户数据库、视频原件、上传记录、Cookie 或密钥。

合成演示 `demo.mp4` 和 `poster.jpg` 由项目生成，作为公开功能演示。

项目代码采用 GPL-3.0-only，与配套 Reading Room 保持一致。
